# Planning centré sur Mission terrain

- Ouvrir le Planning directement sur « Mission terrain », sans les titres explicatifs ni les outils de gestion au-dessus.
- Garder le choix « Je suis : Altaj / Lassana / Tous » immédiatement sous le titre.
- Ajouter « Voir tout le planning » pour afficher la carte, les rendez-vous, l’import et la création ; « Revenir à Mission terrain » les replie sans perdre le client sélectionné.
- Afficher les détails du client sélectionné directement dans Mission terrain : intervention, coordonnées, affectation, informations techniques et notes disponibles.
- Conserver les règles d’affectation, les actions terrain et les confirmations d’envoi existantes, sans modifier les données des chantiers.

## Vérification
Vérifier avec une session réelle l’ouverture, le choix d’intervenant, la sélection d’un client et l’aller-retour vers le planning complet.

## Détails techniques
Limiter les changements à la présentation du Planning ; conserver les outils existants dans une zone repliable et partager la sélection du chantier entre les deux vues.
